## Simplified Technical English (ASD-STE100)

This text loads into an agent's context, often in every session: each word costs tokens.

- One instruction per sentence. Start it with the verb: "Run the tests", not "Tests should be run".
- Keep sentences short: 20 words or fewer for an instruction, 25 for a description.
- Use the active voice.
- Use one word for one thing. Do not change it for a synonym.
- Use the terms of the Acme ubiquitous language.
- Use a list for steps, a table to compare.
- Give the reason in one short sentence when a rule is not obvious.
- No filler: no "please", no "it is important to note that".
- Do not repeat what another loaded file already says. Point to it.
- Delete an instruction the agent follows without being told.
