# Landing page glossary

Sub-domain of the Acme ubiquitous language. The core terms load at session start;
this part loads only when the work is about the landing page.

| Term | Code name | Meaning |
| --- | --- | --- |
| Landing page | `LandingPage` | The page that presents the course. Aggregate root. |
| Feature | `Feature` | A selling point of the course. |
| Chapter | `Chapter` | A part of the course program, with its topics. |
| Step | `Step` | A part of the training format. |
| Waitlist | `waitlist` module | People who want news about the course. No real sign-up. |
| Subscriber | `Subscriber` | A person on the waitlist, identified by email. |
