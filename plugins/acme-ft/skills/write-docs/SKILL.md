# Write docs

@${CLAUDE_PLUGIN_ROOT}/shared/plain-language.md

## For documentation

- Start with who the doc is for and what they can do with it.
- Use headings that say what the section contains.
- Keep sections short: one topic each.
- Define a term the first time you use it.
- Put each command in its own code block, ready to run.

Before you finish, check: can a new reader do the task with this doc only?
