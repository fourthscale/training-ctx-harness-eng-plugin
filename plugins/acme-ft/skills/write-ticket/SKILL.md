# Write a ticket

@${CLAUDE_PLUGIN_ROOT}/shared/plain-language.md

## For a ticket

- Title: the need or the problem, not the solution.
- Context: who needs it and why, in two or three sentences.
- Acceptance criteria: one line per point that a reviewer can check.
- For a bug: steps to reproduce, expected result, actual result.
- Out of scope: what the ticket does not cover, when it could be misread.
- Write in the language the team uses in that tool.
